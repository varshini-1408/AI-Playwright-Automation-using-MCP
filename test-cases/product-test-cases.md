# SauceDemo Product Test Cases

## Test Case 1: View product details

- **Test Case ID:** TC-PRODUCT-007 (REQ-007)
- **Test Case Name:** Logged-in user can select a product and view its details
- **Module:** Products and Product Details
- **Priority:** High
- **Preconditions:** User is logged in and the Products page is displayed.
- **Test Data:** Sauce Labs Backpack.
- **Steps:**
  1. View the available products on the Products page.
  2. Select Sauce Labs Backpack.
- **Expected Result:** The product details page displays the Sauce Labs
  Backpack image, name, description, and price.

## Test Case 2: Add selected product to the cart

- **Test Case ID:** TC-PRODUCT-008 (REQ-008)
- **Test Case Name:** Logged-in user can add a selected product to the cart
- **Module:** Products and Shopping Cart
- **Priority:** High
- **Preconditions:** User is logged in and the Products page is displayed.
- **Test Data:** Sauce Labs Backpack.
- **Steps:**
  1. Select Sauce Labs Backpack from the available products.
  2. Add the product to the cart using the available Add to cart action.
  3. Open the cart.
- **Expected Result:** The shopping cart displays Sauce Labs Backpack as the
  selected product.
